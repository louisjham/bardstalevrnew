# 🎨 The Bard's Tale I - Master Sprite Sheets Archive (01 to 63)

This directory contains the authentic 1985 ripped sprite sheets for **The Bard's Tale: Tales of the Unknown** across both **Amiga** (32-color high-contrast) and **Atari ST** (16-color) releases.

All sheets are standard **1024×256 pixels**, containing 4 horizontal animation frames of **256×256 pixels** each.
